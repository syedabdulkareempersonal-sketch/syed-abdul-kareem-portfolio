How I work

Idea to shipped, fast.

AI removes the slow parts. What is left is deciding what to build and keeping the quality high.

01

Define the thing

I start with who it is for and what one job it has to do. The scope is settled before a single screen exists, so nothing gets built twice.

02

Build it with AI

Design, code and content are produced with Claude, ChatGPT and Antigravity, with open-source models for work that runs locally. I review every output rather than shipping the first result.

03

Ship and sharpen

It goes live, then I use it, find what is clumsy and fix it. Each project teaches the next one something.
